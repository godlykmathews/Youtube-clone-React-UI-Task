# YouTube Clone - React UI Task

A responsive YouTube-inspired user interface built using React. This project focuses on recreating the look and feel of YouTube's frontend, including the navigation bar, sidebar, video cards, and responsive layout.

## 🚀 Features

* Responsive YouTube-like layout
* Modern React component architecture
* Video card grid design
* Sidebar navigation
* Search bar UI
* Mobile-friendly design
* Clean and reusable components

## 🛠️ Tech Stack
